# Slidecast

A beautiful, single-file presentation app — ready to run anywhere.

## What is this?
Slidecast is a self-contained HTML presentation / slide deck project. No build step needed. Just open index.html — perfect for phone copy.

## How to use
1. Open index.html in your browser
2. Present, share, or host on GitHub Pages
3. Edit the slides directly in the HTML file

## Deploy to GitHub Pages (Phone)
1. Create a new repository on github.com (name it slidecast)
2. Tap Add file -> Create new file -> name it index.html -> paste the code
3. Create second file README.md -> paste this file
4. Go to Settings -> Pages -> Source: main branch -> Save
5. Your site will be live at https://yourusername.github.io/slidecast/

## Features
- 100% client-side, no server needed
- Mobile friendly & offline
- One file = whole app
